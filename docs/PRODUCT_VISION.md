# Pandoracle product vision

Pandoracle makes heterogeneous local datasets searchable without surrendering
source provenance or requiring a hosted service. A user should install one command,
import a CSV by confirming what each column means, search across datasets in private,
and open the exact original record behind every result.

The product is intentionally narrow: offline-first, single-user, single-writer, and
CLI-only. It is not an entity-resolution engine, case-management system, general SQL
frontend, or encryption manager. Search acceleration is optional derived state;
original records and stable references remain authoritative.

The v1 quality bar is human workflow clarity and durable local operation. Search and
storage architecture are fixed while the remaining large-corpus performance campaign
is completed.
